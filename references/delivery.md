# 成稿与交付

仅在成稿、保存或检查交付结果时读取；讨论节奏与修改边界见入口。

## 整理与保存

把有效资料和当前决定映射到模板，删除填写提示、占位行和标题中的填写标记，保留实际未知、来源及历史记录。公司文档信息与修订表放目录前，来源放第 9 章；“编制”保留首版作者，本次变更人填“修订人”。个人 PAT 的实际认证姓名可作修订人，身份未知不猜测；历史编审记录注明所属版本，不沿用为当前批准。

默认在用户工作区根目录保存 `<需求名>.md`（名称未定用 `prd.md`），另存并保留原稿，重名用新版本名；用户指定目录或明确更新文件时遵循指令。正文采用的图片按 [图片规范](prototype-analysis.md)配套。Confluence 默认先实际保存并回读本地 Markdown 和图片，再发布；明确仅远程时才省略本地稿。内部 Artifact、聊天代码块、临时 Storage 不算本地交付。

局部更新 Confluence 时，本地稿反映保留范围外内容后的完整结果；不能将本地镜像反向转换后覆盖整页。两种格式核对正文、版本和条目一致。

## 澄清记录与状态

实际发生澄清的编写或优化任务，交稿时另附 `<需求名>_澄清决策记录.md`，与主稿同目录并沿用已有记录；用户明确不要时省略。记录关联稿件／版本、问题与背景、实际候选及取舍、真实回答或未决、主稿位置；回答改变时保留必要替代关系，当前要求以 PRD 为准，不复制全部聊天或维护第二套规则。

讨论期间不要求每轮存文件。只检查或未发生澄清的快捷任务不强制记录。仅远程交付时使用用户授权的附件或记录页面，不自动新建范围外页面；无法交付则说明并提供可复制内容。

| 状态 | 使用条件 |
|---|---|
| 待补充工作稿 | 目标、范围或主要行为仍无法理解，保存已知与缺口 |
| 初版待核对 | 主要内容可理解，已知规则入文、未决显式，完成本轮检查，待产品核对 |
| 可供团队讨论的初版 | 产品已认可本轮稿件用于讨论，允许保留专业未决 |

脚本通过不升级产品状态；这些状态均不代表正式评审、研发批准或测试通过。

## 校验

完成内容规范中的复核，再对实际保存的本地 Markdown 执行（路径相对 Skill 根目录）：

```text
python scripts/validate_prd.py <稿件> --profile template
python scripts/validate_links.py <稿件> --format markdown --profile template
```

完整稿用 `template`；未完成工作稿用 `draft`；输入旧稿诊断用 `existing`，后者不能判定新稿合格。结构检查覆盖模板、编号、占位及图片路径；引用检查覆盖名称、定义和链接目标。静态通过不证明业务正确、像素可读或实际点击有效。

基于已有文稿优化时，结构及组合检查均加 `--source <原始正文快照>`（Markdown／HTML／Storage；不是页面 URL；使用前文暂存的快照文件，如 `.source_snapshot.md`）。源稿有图而输出零图会报错，引用数量减少会提示核对（应在决策记录或第 8 章说明排除／替换依据，形成闭环）；同时检查 Markdown 有图但 Storage 零图的转换遗漏。数量不能证明逐图保留，仍按图片规范核对；未提供源稿时不得称已验证图片继承。用户明确只要纯文字时可不执行源图保留对照，并说明该选择。

图片默认 `local`；仅用户明确外链时给结构检查加 `--image-policy external`。仅目标阅读器确实无法跳转时，给引用检查加 `--reference-policy location`：接受内容规范中的“〔名称（编号）；位置：准确章节标题〕”，仍检查名称、唯一完整定义和章节归属，并披露未验证跳转。普通裸编号、错误链接或错误位置仍失败，不能为消除错误擅自降级。

Confluence 最终待提交和回读的 Storage 分别运行：

```text
python scripts/validate_delivery.py <Storage文件> --workspace <工作区根目录> --markdown <已保存Markdown>
```

组合检查包括 Markdown 结构／图片／引用、Storage 原生引用和目录骨架、两稿定义编号集合；正文语义一致、实际渲染与授权范围 diff 另行核对。按实际条件使用例外参数：

- `--output-dir <目录>`：用户指定其他本地目录。
- `--remote-only` 并省略 `--markdown`：用户明确仅远程。
- `--layout inline`：用户明确正文目录。
- `--image-policy external`：用户明确外链图片。
- `--reference-policy location`：实际跳转能力受限，已标明章节位置与限制。

新完整稿检查有错先修复再发布；无法运行或超出解析能力时保留工作稿并准确报告未检查部分。局部修改只修授权范围及已授权关联项，范围外旧问题单独报告，区分本轮检查与全稿通过。脚本不能核实授权或阻止绕过它的工具调用。

最终提供真实文件／页面链接、修改摘要和遗留项，分别说明内容、静态检查、落盘／写入和显示结果。工具缺失、附件未取得或写入失败不能报告完成；MCP 的 `content_file` 可能是服务端路径，未核实共享路径时使用正文参数。
