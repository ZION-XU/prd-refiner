# 原型与图片分析

涉及界面原型、截图或视觉资料时读取。本文只管“读别人给来的画面”；自己设计交互与出帧见 [交互与原型设计](interaction-design.md)。

## 原型分析准则

- **使用 VLM 查看**：分析界面控件、文案、单位、状态反馈或排查图文冲突时，必须使用 VLM 查看对应原型画面。远程原型图先按 [来源快照](snapshot.md) 落本地，再对快照画面做 VLM 实查。
- **像人一样求实，严禁脑补**：原型仅证明其实际呈现的可见事实。若原文已有原型图，正文未详述的界面细节（如菜单路径、控件文案、布局方位），可保持原样仅引原图；若要在正文中补写展开，其细节必须严格来自 VLM 实际查验结果，绝不凭经验编造推测。
- **图文冲突处理**：发现图文不一致时，说明画面位置、正文原述及具体差异；若涉及产品业务取舍，交由产品决定，不自行推测采纳哪一方。
- **画面局限**：静态图不能证明动态交互，输入框显示值不自动成为默认规则。未看清或图片缺失时说明影响范围，不扩大断言。
