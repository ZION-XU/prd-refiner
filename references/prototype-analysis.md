# 图片、原型读取与资产交付

输入或输出涉及图片、文稿内嵌图、远程附件、Figma 等原型链接或 HTML 时读取本规范。资料来源由用户决定，按宿主实际能力读取；不因图片来自企业系统而跳过。图片读取用于理解和诊断，资产保存用于交付，两者分别核实，不以图片在工具响应中可见代替已保存到本地。

## 按可用能力取得所需图片

先识别本次分析和正文实际需要的图片／原型画面及其来源。主动使用宿主已授权的连接器、MCP、API、下载或浏览器导出能力取得内容，不要求用户另说“下载图片”，也不要求用户自己编写工具。遵守实际工具的调用、权限和文件访问边界；Skill 规则本身不提供账号权限或下载能力。

- **本地或导出文稿**：定位实际图片文件、内嵌媒体或附件，按需要提取或复制。
- **Confluence 等远程文稿**：正文读取成功不等于附件已取得；解析实际采用的图片引用，通过已有授权能力获取对应附件二进制或有效下载地址，再保存文件。只有附件名称或 URL 不算取得图片。
- **Figma 等原型链接**：链接指向设计文件／节点，不是可直接下载的图片。根据相关节点使用实际可用的导出、截图或 API 能力取得画面；需要保留原图时使用可用的原始资源导出。优先取得适合阅读的完整相关画面，不盲目导出所有图层。截图注明来源节点与可见范围，不把静态图称为完整交互原型。
- **工具返回临时 URL、内嵌图像或文件路径**：按该工具支持的方式取得实际文件；只有 URL 时继续下载，只有内嵌图像时通过可用导出能力保存；返回路径时核实该路径确实位于宿主可访问位置。不能把远程 MCP 服务器路径当成本机文件。

一种方式不可用时，可尝试当前已有且允许的其他方式；权限不足、缺少导出／下载能力或必要授权时，说明具体缺口并请求最少的补充。不能绕过访问限制、无限重试或假称已完成；不批量下载未采用的附件。MCP 是一种可选实现，不要求每个来源都安装专属 MCP。

## 实际读取和证据

使用宿主提供的图像查看能力真正检查相关图片，不能根据文件名或周围文字猜画面。HTML 能读取源文时可提取控件和文字；需要验证交互且宿主具备浏览器能力时才检查相应交互。静态截图或源代码不能证明实际软件的状态转换和异常策略。

在相关功能内简记来源、可观察内容及局限。重点核对与本次需求有关的文案、控件状态、单位、入口和操作反馈；不要求每张图都生成 UI 编号或整套状态表。

无法读取某图、页面或附件时，明确未验证哪些内容及影响，必要时请求可读材料。其他资料继续处理。不得仅凭扩展名、附件标题或页面可访问就声称图片内容已检查。

## 图文冲突与优先关系

- 图文一致时保留必要引用；一致也不意味着参考已经成为产品承诺。
- 图中才有的内容作为观察，业务含义需有依据；不能把输入框显示值直接定为产品默认值。
- 图文冲突时说明双方来源和具体差异；用户未指定优先关系时询问或保留未决。
- 用户明确采用某个版本或行为时更新对应正文，旧图需替换或标记局限；不能只按文件时间判断业务版本。

## 文稿和资产

图片就地放在对应功能、规则或操作旁。文字说明图的作用、版本及约束范围，避免把所有图堆到文末。沿用图片原有含义，不要求每个需求都有图片。

**输出本地 Markdown 时，正文采用的图片默认必须本地化。** 自动在文稿旁建立 `assets/images/`；已有配套 `.assets/images/` 等有效相对目录可沿用。将远程图片下载／导出到此处，本地图片复制到此处；重名时用附件／节点标识等区分，不能覆盖不同图片。无需用户另行要求，无图片时不建立空目录。

正文用相对路径嵌入，如 `![图层列表](assets/images/layer-list.png)`，有空格时使用兼容的转义或尖括号形式。原始页面／节点地址保留为来源；服务器下载地址、临时 URL、绝对路径不能代替正文的配套本地图片。文件与资源目录一起搬移后仍应可用。

交付前逐项核对：所用图片是否都有实际文件、文件非空且可解码、不是误保存的登录页或错误页面，正文引用是否解析到正确文件，画面与对应文字是否匹配。核对 Markdown 图片、引用式图片及 HTML 图片标签；普通超链接不等于已嵌入图片。结构脚本只检查其支持的引用、路径和文件状态，图片解码及语义仍须实际查看。

确实无法取得某图时，在对应位置标明“图片未本地化：原因及影响”，保留可追溯来源并向用户汇总缺口；可交付明确缺资源的工作稿，不能称图片已齐备，也不能仅保留远程嵌入就报告完成。只有用户明确要求保留外链时才采用外链交付，并说明依赖条件；不能为使校验通过擅自改为外链策略或删去必要图片。

**输出到 Confluence 等平台时**，按目的地和当前工具的图片／附件接口形成可用引用。Confluence 默认配套的本地 Markdown 同样遵循上述图片本地化规则，除非用户明确仅远程或保留外链。平台返回成功不等于图像可显示，需按可用能力核对实际结果。

正文承载产品规则和必要交互；不另外生成 `interaction-spec.md`、`traceability-matrix.md` 等并列需求文件。复杂来源比较确有需要时，可在可选附件中记录证据并引用正文。
