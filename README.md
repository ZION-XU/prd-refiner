# PRD Refiner

面向中望 CAD 产品人员的 Agent Skill：编写 PRD 初版，检查、深化、精简或局部修改已有稿，帮助产品把内容交给团队继续讨论。

模板只是固定的输出容器；真正的优化依靠 Skill 的规则提炼、审查诊断，以及与产品经理的交互推敲。默认先基于原始资料讨论，按业务问题推进，不提前映射章节或填表；讨论收敛后才将结果整理进统一 PRD 模板。仅检查任务报告问题，不改稿。

仓库只维护一份 [PRD 模板](assets/prd-template.md)。已有 PRD 是输入文稿，不代表另一套模板；`template`、`draft`、`existing` 是校验模式。模板内保留供人和 AI 使用的填写提示，出稿时清除；提问、工具和文件处理规则由 Skill 维护。

输出默认用“名称（编号）”呈现条目，引用带业务含义和必要概述，并按阅读器或平台能力链接到定义。读者不点击链接也能理解当前功能与验收，需要完整条件和例外时再跳转；稳定编号继续用于定位和追踪。规则集中定义，修改时同步核对引用概述与链接。

多功能、跨角色或范围取舍复杂时，按需用总体流程与用户故事地图帮助讨论，成稿放在模板 1.3；单功能详细流程仍放在对应功能下，不强制同时出两种图。知识产权在 7.3 分为风险点分析与可专利点分析，未分析标待评估，已有依据才能填写“无”；第 0 章继续承担摘要作用。

Confluence 输出默认不使用代码宏呈现图示；原型、故事地图和流程采用原生排版或已渲染图片。故事地图可用活动色带和任务卡片增强层次，独立 HTML 的高级样式不自动等同 Confluence 内可保留的格式。

编写和优化默认逐轮讨论：需求、已有 PRD、原型和澄清回答都是资料，先提炼规则、诊断，再与产品经理推敲，不默认先写初稿再补齐。已有文稿的方案也可重新审视，不能只围着原结构修补。每轮聚焦一个关键问题，等待回答后继续；内容收敛后才按模板成稿。只有明确要求“直接生成／先出稿／不用讨论”，或仅检查、精简措辞、按具体指令修改时走快捷路径。初版不代表正式评审通过。

资料来自哪里、输出到哪里、是否通过 MCP 读写均由用户决定，不改变上述工作流。未指定目的地时保存工作区根目录 Markdown；指定 Confluence 时默认先保存该本地稿，再以经过检查的 Storage 发布，用户明确指定其他目录或仅远程时遵循其选择。已有转换能力可用于准备正文，转换结果仍须检查。

实际发生澄清的编写或优化任务，交稿时另附澄清决策记录，保留真实问题、候选、取舍与回答，并引用主稿；未发生澄清的快捷任务不强制生成。指标区分已确认要求、产品人员建议和 AI 建议目标，缺依据时保持未知。只有明确要求写入 Confluence 时才加载专门交付规范，按可用能力处理原生目录和排版；提供页面链接作为资料不代表要求写入。

写入 Confluence 必须明确页面及操作范围：已有页面区分局部修改／追加与整页替换，未经明确授权不覆盖；新建时结合需求和提示词展示空间、父级页面路径及拟建标题，由用户确认拟定位置，或由用户先建页再提供写入地址。目标或方式不明时先准备内容并等待澄清，不能自行选页写入。

修改已有页优先使用精确定位的章节更新；需要整页提交时，在最新 Storage 上合并必要修改并保留其他内容，避免整页格式往返转换。修改后回读实际版本并核对 diff，使差异集中于授权变更；版本 diff 不可用时对照前后正文并说明检查范围。

本地 Markdown 默认自动配套保存所用图片：通过宿主已有授权工具取得 Confluence 附件、Figma 相关画面或其他必要图片，放入文稿旁的 `assets/images/`（可沿用已有 `.assets/images/`），正文用相对路径嵌入。无需另行要求下载；缺少权限或导出／下载能力时明确说明缺图，不声称已完成。Skill 不自带账号权限，也不要求每种来源都安装 MCP；宿主具备可用的连接器、API 或浏览器导出能力即可按实际情况执行。

## 宿主安装与配置

本仓库是一个标准的独立 Agent Skill，无需安装脚本或依赖编译，直接放置或链接到对应 Agent 宿主的 Skill 目录即可生效：

- **全局配置**：将本仓库目录软链接（符号链接 / Junction）或复制到所用 Agent 宿主的全局 Skill 目录下，例如：
  - Antigravity / Gemini CLI：`~/.gemini/antigravity/skills/prd-refiner`
  - Claude Code：`~/.claude/skills/prd-refiner`
  - OpenAI Codex / 其他支持 Skill 规范的宿主：对应的全局 skills 目录
- **项目/工作区配置**：若仅在特定项目中使用，可直接将本仓库放置或链接至该项目根目录下的 `.agents/skills/prd-refiner`（或 `.agent/skills/prd-refiner`）。

开发与使用时建议使用目录软链接指向同一份源文件，避免副本漂移。

## 使用

通过宿主支持的方式调用（例如显式调用 `$prd-refiner` 或 `/prd-refiner`），例如：

```text
$prd-refiner 通过已有 MCP 读取我指定的 Confluence 页面，我们一起优化一下。
$prd-refiner 根据这些资料直接生成一份初版，不能确定的内容标明。
$prd-refiner 我只有一个想法：统计图纸里的设备。帮我厘清任务、比较必要的方案，再逐步写成 PRD。
$prd-refiner 只检查这份 PRD 的歧义和遗漏，不改文件。
$prd-refiner 精简这份 PRD，保留原有规则和数值。
$prd-refiner 按这条变更修改 FR-002，保持其他功能，检查相关验收。
```

讨论收敛后按用户指定位置输出；未指定时在工作区根目录保存 `<需求名>.md`（名称未定用 `prd.md`），可按版本另存。Confluence 默认配套同内容的本地 Markdown 和图片，隐藏 Artifact 不算交付；最终分别提供文件和页面链接。每轮对话不要求交稿，源稿默认保留，明确要求更新时按指令执行。用户核对后可带着明确未决事项进入团队讨论，不强制多份需求附件。

## 用旧 PRD 实测

直接提供旧稿和优化目的，无须额外要求迁移模板：

```text
$prd-refiner 优化这份旧 PRD，保留有效规则、数值、来源与必要图片；缺口先指出，不能确定的内容标明，按 PRD 模板另存优化稿，分别说明结构调整和内容变更。
```

新稿编写和旧稿优化都检验模板与 Skill 的配合。局部修改也使用模板框架，但其他功能的含义保持。保留原稿、实际问答、输出和人工核对记录，便于发现实际遗漏、错误补充及意外改动；真实需求与输出放在仓库外。

## 验证与维护

Python 3.10 及以上可运行标准库校验与回归：

```text
python scripts/validate_prd.py <文稿路径> --profile template
python scripts/validate_links.py <文稿路径> --format markdown --profile template
python scripts/validate_delivery.py <Storage文件> --workspace <工作区根目录> --markdown <本地Markdown文件>
python -B -m unittest discover -s scripts -p "test_validate*.py"
```

新编和优化初版均使用 `--profile template`，按模板组织的未完成工作稿使用 `--profile draft`；`--profile existing` 仅诊断输入旧稿，不检查 PRD 模板框架，不能用于判定优化输出合格。脚本通过只说明已检查的结构，不证明业务正确或正式评审通过。

结构与引用是两项检查，原结构脚本通过不能替代引用检查。Confluence 对最终待提交正文和回读 Storage 分别运行 `validate_delivery.py`，同时检查本地 Markdown、编号链接和默认浮动折叠目录；缺少任一项不能报告完整交付。中望目录采用文首原生右侧格承载整个浮动折叠容器，后续正文单独全宽，复用站点样式而不写内联定位；用户已确认改标题并保存后仍正常。可复用骨架见 [confluence-toc.xml](assets/confluence-toc.xml)，站点适用前提见 [交付规范](references/publish-confluence.md#目录与布局)，明确例外参数见 [交付检查](references/review.md#交付检查)。脚本通过只证明静态结构，其他站点显示效果、两份正文语义一致性及授权范围内的 diff 仍须核对。

入口只保留关键约束及阶段路由：首次诊断或编写前读取内容标准，内容提炼时读取细化方法，提问前读取澄清方法，成稿前读取模板，交付前执行内容与链接检查。同一方法仍在上下文中时复用。维护时检查文件是否实际被宿主读取以及产物是否符合要求，不能仅检查入口是否含有链接或“必须”字样。

本地输出默认要求图片本地化：完整稿中的远程图片、绝对／越出文稿目录的路径及缺失文件会报错；工作稿中的未本地化项给出提示，仍应明确交付缺口。只有用户明确保留外链时才加 `--image-policy external`；来源链接不受图片策略影响。脚本不联网下载，也不验证图片画面，交付仍需实际查看。
