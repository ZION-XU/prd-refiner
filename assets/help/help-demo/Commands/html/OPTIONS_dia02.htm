设置对象选择的预览效果。

区域选择效果

控制选择过程中的选择区域的外观。

指示选择区域

勾选此项，在选择过程中将使用不同的背景色指示窗口或窗交选择。

该设置储存在系统变量 SELECTIONAREA。

窗口选择颜色

设置使用窗口选择时透明选择区域的颜色。

该设置储存在系统变量 WINDOWAREACOLOR。

交叉选择颜色

设置窗交选择时透明选择区域的颜色。

该设置储存在系统变量 CROSSINGAREACOLOR。

选择区域不透明

设置选择区域的透明度，可以直接在编辑框中输入数值，或通过拖拽滑块来设置。取值范围为 0 ~ 100。当设置值为 100 时，则选择区域不透明。

该设置储存在系统变量 SELECTIONAREAOPACITY。

选择集预览过滤器

控制选择集预览过滤的对象类型。

该设置储存在系统变量 PREVIEWFILTER。

锁定图层上的对象

选择集预览中过滤锁定图层上的对象。

外部参照

选择集预览中过滤外部参照中的对象。

表格

选择集预览中过滤表格。

组

选择集预览中过滤编组中的对象。

多行文字

选择集预览中过滤多行文字。

图案填充

选择集预览中过滤选择填充对象。
