# Figma 集成边界

当前核心 Skill 不依赖 Figma API。收到 Figma 链接时，优先使用宿主已有的浏览器、连接器或 MCP；无法访问时，要求用户提供截图、导出文件或交互说明，并继续完成 PRD 优化。

## 未来连接器契约

Figma 连接器只负责提供可观察证据，不直接决定业务规则。建议返回：

- 文件、页面、Frame、组件和 Variant 的稳定标识与名称；
- 可见文本、组件类型、默认值和状态；
- 原型连接、触发动作、目标页面和覆盖路径；
- 文件版本、更新时间和访问范围；
- 无法读取或未覆盖的节点与交互。

核心 Skill 将连接器结果标记为“原型观察”，与 PRD 对齐后按以下规则处理：

1. PRD 与原型一致：共同作为来源；
2. 仅 PRD 存在：记录“原型未体现”；
3. 仅原型存在：记录“PRD 未定义”；
4. 两者冲突：创建澄清项，由产品经理确认；
5. API 不可用：降级到截图或产品经理交互。

## 安全与配置

- 不在 Skill、插件清单或输出文档中保存访问令牌；
- 由宿主平台或用户环境管理认证；
- 只请求完成当前需求所需的最小只读权限；
- 在真正提供 MCP 或 API 配置文件之前，不在插件清单中声明不存在的连接器。
