# Confluence 交付规则

本规则用于产品经理确认需求基线后的可选企业交付。Confluence 只是交付目的地，不改变十二维需求模型、证据边界、澄清结论或六文档需求包。

## 启用条件

仅在以下条件同时满足时执行在线写入：

1. 用户明确要求写入 Confluence；
2. 已完成或透明终止需求澄清；
3. 本地六文档需求包已生成并通过可执行的校验；
4. 目标空间、父页面、标题和创建/更新方式已确定；
5. MCP 工具可用，且用户确认写入预览。

公司 Confluence 地址固定为 `https://confluence.zwcad.com`。身份由宿主 MCP 启动器从仓库外的用户配置读取。不要向用户索要明文 PAT，不要读取、显示、复制或写入 PAT。

## 写入预览

执行前列出：

- 目标空间与父页面；
- 拟创建或更新的页面标题；
- 创建、更新或跳过动作；
- 正文来源及稳定需求 ID 范围；
- 拟写入的图片、图片来源页面/附件名或公开 URL，以及需要上传的本地文件；
- 待确认项和风险的页面呈现方式；
- 失败后的重试边界。

获得产品经理明确确认后才能调用写工具。正式页已存在时默认更新前先读取当前版本，不静默覆盖无法识别的既有正文。

## 执行与校验

1. 先用搜索或页面读取工具解析空间键、父页面 ID、目标页面 ID 和当前版本；
2. 根据已确认计划调用页面创建或更新工具；
   - 普通章节标题使用原生 `h1`～`h6`，不要自动插入 Anchor 宏；仅在需求明确包含章节跳转链接时显式创建 Anchor；
3. 图片已附加在 Confluence 页面时，用 `ac:image > ri:attachment > ri:page` 原生格式引用来源页面和附件名；不要把需要登录的附件下载地址写成 `ri:url`。只有公开且无需登录即可读取的外部图片才可使用 `ri:url`。本地图片仅在宿主 MCP 暴露上传工具时逐项上传，否则明确保留为待交付项；
4. 写入后重新读取页面，核对页面 ID、空间、父级、标题、版本和关键内容标记；
5. 执行过附件上传时重新读取附件清单，核对文件名、数量和归属页面；
6. 将页面 URL、页面 ID、版本和执行状态写入交付说明及追溯矩阵；
7. 部分成功时分别记录成功、失败和待重试项，不把部分成功报告为完成。

## 安全边界

- 未确认内容必须继续标为待确认；
- 不删除页面或附件，除非用户明确指定测试对象并授权删除；
- 不扩大到用户未指定的空间或页面层级；
- 不在日志、回复、需求包或仓库中输出凭据；
- MCP 不可用时保留本地需求包和写入计划，不伪造在线交付结果。
