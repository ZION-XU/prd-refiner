# CAD 图层状态批量设置（原始需求示例）

> 本案例为教学与插件验证而合成，不对应任何真实产品或未公开项目。

## 需求说明

图层比较多的时候，一个一个修改开关、冻结和锁定很麻烦，希望在图层管理器里面支持批量设置图层状态，提高用户处理复杂图纸的效率。

用户可以多选图层，然后点击批量设置，选择要修改的状态。设置之后列表要马上更新，图纸也要刷新。这个功能需要支持撤销，操作要快，不能卡顿。

外部参照的图层和当前图层可能需要特殊处理，具体按 CAD 现有规则。界面参考原型。

## 大致交互

1. 打开图层管理器；
2. 选择多个图层；
3. 点击批量设置；
4. 选择开/关、冻结/解冻、锁定/解锁；
5. 点击确定后修改。

## 验收

- 可以批量修改图层；
- 操作结果正确；
- 性能正常；
- 可以撤销。
