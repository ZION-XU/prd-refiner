# 2. 背景、目标、范围与非目标

## 背景

复杂 CAD 图纸可能包含大量图层。用户逐项修改可见性、冻结和锁定状态时操作重复且容易遗漏。

## 目标

允许用户在当前图纸的图层管理器中选择多个本地图层，一次设置一类或多类图层状态，并获得明确的成功、跳过和撤销反馈。

## 成功指标

- 批量操作可作为一个撤销单元恢复；
- 对不可修改图层不产生非法状态；
- 在 `NFR-001` 的基准负载下满足响应时间要求；
- 主流程、特殊图层和部分成功均有可验证验收标准。

## 范围

- 当前打开图纸；
- 本地图层的开/关、冻结/解冻、锁定/解锁；
- 工具栏和右键菜单入口；
- 部分成功、结果汇总和单步撤销。

## 非目标

- 跨图纸批量修改；
- 修改外部参照图层定义；
- 修改颜色、线型、线宽等其他图层属性；
- 提供可取消的长任务进度条。

# 3. 角色与术语

| 角色/术语 | 定义 |
|---|---|
| CAD 用户 | 对当前图纸具有编辑权限并使用图层管理器的用户 |
| 本地图层 | 由当前图纸直接定义、非外部参照引入的图层 |
| 当前图层 | 当前 CAD 绘图状态下用于创建新对象的活动图层 |
| 跳过 | 不修改目标图层，但继续处理选择集中的其他合法图层 |
| 保持不变 | 本次批量操作不得改动该状态字段 |

# 4. 场景与流程

## 主场景

1. 用户打开当前图纸的图层管理器。
2. 用户选择两个或更多图层，也允许只选一个图层以保持入口行为一致。
3. 用户从工具栏或右键菜单打开“批量设置图层状态”。
4. 对话框显示选择数量，并为可见性、冻结状态和锁定状态分别提供“保持不变”及目标值。
5. 用户至少指定一项变化后点击“应用”。
6. 系统判断每个图层和目标状态是否合法，修改合法项，跳过非法项。
7. 系统刷新图层列表和绘图区，显示成功数、跳过数及跳过原因。
8. 用户可以执行一次撤销，恢复本批次成功修改的全部状态。

## 替代与异常流程

- 未选择图层：两个入口均禁用。
- 三类状态均为“保持不变”：“应用”按钮禁用。
- 当前图层被要求关闭或冻结：跳过当前图层，其他合法图层继续。
- 外部参照图层：跳过，不修改引用定义。
- 操作时间超过 500 毫秒：显示忙碌状态，完成后恢复正常交互。

# 5. 功能需求

## FR-001 打开批量设置并定义目标状态

- 角色：CAD 用户。
- 前置条件：已打开可编辑图纸和图层管理器。
- 触发条件：选择至少一个图层后点击工具栏“批量设置”，或打开选择集右键菜单中的同名入口。
- 主流程：显示选择数量；分别选择可见性、冻结和锁定的目标值；至少一项非“保持不变”后允许应用。
- 结果：生成本次批量状态变更请求。
- 关联规则：`BR-001`、`DATA-001`。
- 来源与澄清：`SRC-PROTOTYPE-01`、`CL-002`、`CL-007`。

## FR-002 执行批量状态修改并反馈结果

- 角色：CAD 用户。
- 前置条件：存在有效批量状态变更请求。
- 触发条件：用户点击“应用”。
- 主流程：逐项校验目标图层；修改合法项；跳过非法项；刷新列表和绘图区；汇总结果。
- 结果：显示成功数、跳过数和按原因分组的图层名称。
- 关联规则：`BR-002`、`BR-003`、`BR-004`、`NFR-001`。
- 来源与澄清：`SRC-PRD-01`、`CL-001`、`CL-003` 至 `CL-006`。

# 6. 业务规则、数据与状态

## BR-001 独立状态字段

可见性、冻结和锁定三个字段独立生效。字段值为“保持不变”时，不得读取其他图层值覆盖它，也不得重置为默认值。来源：`CL-002`。

## BR-002 当前图层限制

当目标为“关”或“冻结”且对象是当前图层时，系统跳过该图层；锁定和解锁当前图层允许执行。来源：`CL-003`。

## BR-003 特殊图层与部分成功

外部参照图层及宿主判定为不可修改的图层必须跳过；合法本地图层继续执行。系统按原因汇总所有跳过项，不因单个非法图层回滚已成功的合法项。来源：`CL-001`、`CL-004`。

## BR-004 撤销单元

一次点击“应用”产生一个撤销单元。撤销恢复本批次中所有成功修改图层在操作前的三类状态，不处理本批次未修改或跳过的图层。来源：`CL-005`。

## DATA-001 批量状态请求

| 字段 | 可选值 | 默认值 | 约束 |
|---|---|---|---|
| visibility | unchanged / on / off | unchanged | 与其他字段独立 |
| frozen | unchanged / freeze / thaw | unchanged | 当前图层不允许 freeze |
| locked | unchanged / lock / unlock | unchanged | 当前图层允许修改 |
| selectedLayerIds | 图层稳定标识集合 | 当前选择集 | 至少一个；执行时再次校验对象有效性 |

三个状态字段不能同时为 `unchanged`。来源：`SRC-PROTOTYPE-01`、`CL-002`、`CL-007`。

# 7. 权限、接口与依赖

- 用户必须具有当前图纸编辑权限；只读图纸不开放批量设置入口。
- 功能依赖宿主 CAD 的图层状态修改、图形刷新和撤销栈接口。
- 外部参照图层视为只读证据，不通过本功能修改。
- 不新增网络接口，不上传图纸或图层数据。

# 8. 异常、边界与非功能需求

| 场景 | 系统行为 | 用户反馈 | 恢复方式 |
|---|---|---|---|
| 选择为空 | 禁用入口 | 无 | 选择图层 |
| 三项均保持不变 | 禁用应用 | 无 | 指定至少一个目标状态 |
| 当前图层要求关闭/冻结 | 跳过当前图层 | 汇总显示原因 | 更换当前图层后重试 |
| 包含外部参照/只读图层 | 跳过非法项，处理合法项 | 汇总显示原因 | 修改来源定义或权限后重试 |
| 图层在对话框打开后被删除 | 执行时跳过失效标识 | 汇总显示“对象已不存在” | 重新选择 |
| 所有目标均被跳过 | 不创建无效撤销记录 | 显示 0 成功及原因 | 调整选择或目标状态 |

## NFR-001 批量处理性能

在测试计划记录的基准设备、包含 10,000 个本地图层的图纸中，对 5,000 个图层应用单类或多类状态变更，从点击“应用”到列表和绘图区完成刷新不超过 2 秒；超过 500 毫秒时显示忙碌状态。来源：`CL-006`。

## 待确认的非阻塞项

- 不同语言版本的结果汇总文案和图层名称截断规则尚待 UX 文案评审；不影响核心行为实现。

# 9. 验收标准

## AC-001 入口和空操作保护

- Given：图层管理器未选择任何图层；
- When：用户查看工具栏或右键菜单；
- Then：“批量设置”入口不可用。
- 关联需求：`FR-001`、`CL-007`。

## AC-002 仅修改指定状态

- Given：选择两个本地图层，可见性选择“关”，冻结和锁定均为“保持不变”；
- When：用户应用设置；
- Then：两个图层仅可见性变为关闭，原冻结和锁定状态不变。
- 关联需求：`FR-001`、`BR-001`、`DATA-001`。

## AC-003 当前图层限制

- Given：选择集中包含当前图层和一个普通本地图层，目标为“冻结”；
- When：用户应用设置；
- Then：普通图层被冻结，当前图层保持原状态，结果显示 1 成功、1 跳过及原因。
- 关联需求：`FR-002`、`BR-002`。

## AC-004 外部参照图层部分成功

- Given：选择集包含两个本地图层和一个外部参照图层，目标为“锁定”；
- When：用户应用设置；
- Then：两个本地图层被锁定，外部参照图层未改变，结果按原因列出跳过项。
- 关联需求：`FR-002`、`BR-003`。

## AC-005 单步撤销

- Given：一次批量操作成功修改多个图层的多类状态；
- When：用户执行一次撤销；
- Then：本批次成功修改的所有图层恢复操作前状态，跳过项不受影响。
- 关联需求：`FR-002`、`BR-004`。

## AC-006 性能基线

- Given：基准设备和包含 10,000 个本地图层的测试图纸，已选择其中 5,000 个图层；
- When：应用合法状态修改；
- Then：500 毫秒后如未完成则显示忙碌状态，总完成时间不超过 2 秒，结果与实际状态一致。
- 关联需求：`FR-002`、`NFR-001`。

# 10. 实现与测试交接

- 执行前对选择集重新解析，避免对话框打开期间对象变化导致悬空引用。
- 将合法性判断集中在单一规则层，避免工具栏和右键入口行为不一致。
- 测试至少覆盖：全成功、部分成功、全跳过、当前图层、外部参照、对象删除、组合状态、单步撤销和性能负载。
- 性能设备配置、CAD 构建版本和测试图纸生成方法由测试计划固定。
- 本文不规定具体 UI 框架、命令 API 或数据结构实现。
