# 3. 交互规格

## UI-001 图层管理器批量设置入口

- 关联需求：FR-001。
- 来源：SRC-PROTOTYPE-01、CL-007。
- 入口：图层管理器工具栏“批量设置”；图层选择集右键菜单“批量设置”。
- 展现方式：两个入口打开同一个 UI-002 弹窗。
- 可见/可用权限：只读图纸不开放；未选择图层时入口禁用。
- 默认状态：图层选择发生变化时立即更新入口可用状态。
- 操作与跳转：点击任一入口打开 UI-002，不修改图层状态。
- 失败结果：选择对象在打开前失效时，不打开弹窗并刷新列表状态。
- 关联验收：AC-001。

## UI-002 批量设置图层状态弹窗

- 关联需求：FR-001、BR-001、DATA-001。
- 来源：SRC-PROTOTYPE-01、CL-002、CL-007。
- 入口：UI-001。
- 展现方式：模态弹窗，显示“已选择 N 个图层”。
- 关闭或取消方式：取消按钮和右上角关闭按钮；关闭不产生状态修改或撤销记录。
- 控件与字段：可见性、冻结状态、锁定状态三组下拉框。
- 默认状态：三组字段均为“保持不变”。
- 提交条件：至少一组字段选择非“保持不变”值。
- 禁用状态：三组均为“保持不变”时“应用”按钮禁用。
- 提交中状态：转入 UI-003；避免重复提交。
- 成功结果：保留弹窗关闭行为，刷新图层列表与绘图区，并显示结果汇总。
- 失败结果：如果全部对象在执行前失效或不可修改，不产生撤销记录，显示 0 成功和原因。
- 边界与可访问性：键盘焦点顺序和多语言长文本展示待 UX 评审。
- 关联验收：AC-002、AC-003、AC-004。

## UI-003 执行状态与结果汇总

- 关联需求：FR-002、BR-002、BR-003、BR-004、NFR-001。
- 来源：CL-003、CL-004、CL-005、CL-006。
- 入口：UI-002 点击“应用”。
- 展现方式：执行超过 500 毫秒时显示忙碌状态；完成后显示结果汇总。
- 提交中状态：阻止重复应用，不提供取消操作。
- 成功结果：显示成功数量；存在跳过项时同时显示跳过数量和按原因分组的图层名称。
- 失败结果：全跳过时显示 0 成功、跳过总数和原因；不创建无效撤销记录。
- 操作与跳转：完成后关闭弹窗，用户可在 CAD 主界面执行一次撤销。
- 空状态：无跳过项时不展示空的错误分组。
- 边界与可访问性：图层名称过长时的截断和完整名称查看方式待确认。
- 关联验收：AC-003、AC-004、AC-005、AC-006。
