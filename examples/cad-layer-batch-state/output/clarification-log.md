# 需求澄清与决策记录

## CL-001 操作范围与外部参照图层

- 来源：`SRC-PRD-01`“外部参照的图层可能需要特殊处理”。
- 原始表述或原型观察：未说明当前图纸、外部参照和跨文档范围。
- 发现的问题：开发无法确定可操作对象，错误处理和测试范围也无法建立。
- 影响：范围、权限、异常和验收。
- 提问：批量设置应处理哪些图层？
- 候选项：A. 仅当前图纸的本地图层（推荐）；B. 包含外部参照图层；C. 跨已打开图纸。
- 产品经理回答：选择 A；外部参照图层可以被选中看见，但不允许修改。
- 最终决策：功能仅修改当前图纸中的本地图层，外部参照图层跳过并汇总提示。
- 更新的需求/原型：`FR-001`、`BR-003`、`AC-004`。
- 状态：已确认
- 责任人或所需证据：无。

## CL-002 未指定状态字段的处理

- 来源：`SRC-PROTOTYPE-01` 三组下拉框均包含“保持不变”。
- 原始表述或原型观察：原始 PRD 只说“选择要修改的状态”。
- 发现的问题：无法判断一次操作是否覆盖三类状态，可能意外改变用户未选择的属性。
- 影响：核心业务规则和数据状态。
- 提问：用户只指定其中一类状态时，其余状态如何处理？
- 候选项：A. 保持不变（推荐）；B. 重置为默认；C. 使用列表中第一图层的状态。
- 产品经理回答：选择 A。
- 最终决策：每个状态字段独立生效；“保持不变”的字段不得修改。
- 更新的需求/原型：`BR-001`、`DATA-001`、`AC-002`。
- 状态：已确认
- 责任人或所需证据：无。

## CL-003 当前图层的限制

- 来源：`SRC-PRD-01`“当前图层可能需要特殊处理”。
- 原始表述或原型观察：没有给出当前图层可以执行哪些状态变化。
- 发现的问题：关闭或冻结当前图层可能违反 CAD 既有约束。
- 影响：不可逆/非法操作、异常反馈和验收。
- 提问：选择集中包含当前图层，且用户要求关闭或冻结时如何处理？
- 候选项：A. 跳过当前图层，继续处理其他图层并提示（推荐）；B. 整批失败；C. 自动切换当前图层后执行。
- 产品经理回答：选择 A；锁定当前图层允许执行。
- 最终决策：关闭或冻结当前图层时跳过该图层；锁定或解锁仍可执行；其他合法图层继续处理。
- 更新的需求/原型：`BR-002`、`AC-003`。
- 状态：已确认
- 责任人或所需证据：无。

## CL-004 部分成功与反馈方式

- 来源：`SRC-PRD-01`、`SRC-PROTOTYPE-01`。
- 原始表述或原型观察：只要求“列表更新、图纸刷新”，未定义特殊图层混入时的结果。
- 发现的问题：整批失败或部分成功会产生不同的数据一致性和用户预期。
- 影响：主流程、异常、消息和测试。
- 提问：选择集中同时存在可修改与不可修改图层时，是整批失败还是处理合法项？
- 候选项：A. 合法项执行，非法项跳过并汇总（推荐）；B. 任一非法则整批失败；C. 首次遇到非法项时停止。
- 产品经理回答：选择 A。
- 最终决策：采用部分成功；完成后显示成功数、跳过数和按原因分组的图层名称，列表与绘图区反映实际成功结果。
- 更新的需求/原型：`FR-002`、`BR-003`、`AC-004`。
- 状态：已确认
- 责任人或所需证据：无。

## CL-005 撤销粒度

- 来源：`SRC-PRD-01`“需要支持撤销”。
- 原始表述或原型观察：没有定义一次撤销恢复一个图层还是整批操作。
- 发现的问题：命令栈设计和验收标准不明确。
- 影响：CAD 命令行为、状态恢复和测试。
- 提问：一次批量设置应如何进入撤销栈？
- 候选项：A. 整批作为一个撤销单元（推荐）；B. 每个图层一个撤销单元；C. 每类状态一个撤销单元。
- 产品经理回答：选择 A。
- 最终决策：一次点击“应用”产生一个撤销单元，撤销时恢复本次成功修改的全部图层状态。
- 更新的需求/原型：`BR-004`、`AC-005`。
- 状态：已确认
- 责任人或所需证据：无。

## CL-006 性能验收基线

- 来源：`SRC-PRD-01`“操作要快，不能卡顿”。
- 原始表述或原型观察：没有图层数量、设备环境和响应时间。
- 发现的问题：无法验证“性能正常”，也无法判断是否需要进度反馈。
- 影响：非功能、实现策略和性能测试。
- 提问：本期性能基线采用哪一项？
- 候选项：A. 10,000 个本地图层中选择 5,000 个，在基准设备上 2 秒内完成（推荐）；B. 1,000 个图层 1 秒；C. 先不设指标。
- 产品经理回答：选择 A；超过 500 毫秒显示忙碌状态，不需要可取消进度条。
- 最终决策：采用 5,000/10,000 图层、2 秒基线，并提供忙碌反馈。
- 更新的需求/原型：`NFR-001`、`AC-006`。
- 状态：已确认
- 责任人或所需证据：基准设备配置由测试计划记录。

## CL-007 入口与生效按钮

- 来源：`SRC-PROTOTYPE-01`。
- 原始表述或原型观察：原型同时提供工具栏和右键入口，“确定”始终可用。
- 发现的问题：入口范围和空操作行为不清晰。
- 影响：交互一致性和验收。
- 提问：是否保留两个入口，以及没有任何状态变化时如何处理？
- 候选项：A. 保留两个入口；至少一项非“保持不变”时才允许应用（推荐）；B. 仅工具栏；C. 始终允许应用。
- 产品经理回答：选择 A。
- 最终决策：工具栏和右键菜单均提供入口；未选择图层时入口禁用；三项均为“保持不变”时“应用”禁用。
- 更新的需求/原型：`FR-001`、`BR-001`、`AC-001`。
- 状态：已确认
- 责任人或所需证据：无。
