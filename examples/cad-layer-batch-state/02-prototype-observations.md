# 原型观察记录

> 来源编号：`SRC-PROTOTYPE-01`。本文件描述合成原型中直接可见的内容，不代表已经确认的业务规则。

1. 图层管理器工具栏存在“批量设置”按钮。
2. 图层列表支持多选，右键菜单也存在“批量设置”入口。
3. 批量设置对话框包含三组下拉框：
   - 可见性：保持不变 / 开 / 关；
   - 冻结状态：保持不变 / 冻结 / 解冻；
   - 锁定状态：保持不变 / 锁定 / 解锁。
4. 对话框显示“已选择 N 个图层”。
5. 原型中“确定”按钮始终可用，没有展示当前图层、外部参照图层或受保护图层的处理方式。
6. 原型没有展示部分成功、错误提示、撤销粒度和大图纸性能反馈。

## 与原始 PRD 的待对齐项

- 原始 PRD 没有说明两个入口是否都需要；
- “按 CAD 现有规则”没有指出具体规则；
- 原型允许三类状态组合设置，但没有定义未选择字段是否保持不变；
- 对特殊图层和部分失败的反馈未定义；
- “操作要快”没有可测量阈值。
